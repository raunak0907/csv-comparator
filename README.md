# 📊 CSV Comparator using Flask

This is a web-based tool where you can **upload two employee CSV files (Master and Slave)** and:

- See the differences between them
- Find out which employees are new joiners
- Export results as PDF or Excel
- Send reports by email

I built this project using **Flask, Pandas, Bootstrap, and ReportLab** as part of my industrial training.

---

## 🚀 How to Run the Project

1. Make sure Python is installed
2. Install dependencies:
   ``bash
pip install -r requirements.txt
3.Run the app
python app.py


🧪 Technologies Used
Python
Flask
Pandas

📸 Features
Upload 2 CSV files
Show differences in employee data
Show new joinees with selected fields (e.g., SAIL_PERNO, UNIT_PERNO, DATE_OF_JOINING, IFSC_CODE)
Download PDF or Excel report
Email the reports directly
